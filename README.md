# Al Ferdous — Vision Correction Landing Page

Landing page for Al Ferdous Eye Center (English): animated iris intro ("SEE BEYOND" → "SEE CLEARLY") with a booking bar, then treatments, patient journey, self-check, doctors, FAQ and contact.

## Structure
- `index.html`: the whole site (HTML + CSS + JS, no build step, no images needed)
- `media/`: assets from the previous version (not used by the current page)

## Edit
- Open `index.html` in a browser, press **Edit text**, change any text, then **Download HTML** and replace `index.html` with the downloaded file.
- Or edit `index.html` directly in a code editor.
